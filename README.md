## 🤖 AI & Agent Engineering

Beyond consuming AI tools, I build systems on top of them:

- **MCP agent infrastructure** — custom Model Context Protocol servers exposing aggregation tools to LLM agents, designed to keep responses grounded instead of drowning the model in raw JSON.
- **RAG pipelines** — vector search with `pgvector` and Supabase Postgres, backing retrieval-augmented generation flows.
- **LLM orchestration** — workflow automation connecting language models to production databases, BI APIs and messaging channels.
- **Cost engineering** — prompt caching and batch inference strategies to keep agent workloads economically viable at scale.
